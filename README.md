# kadin-ve-genc-guvenligi-paneli
# ⚖️ Kadın ve Genç Güvenliği - Bölgesel Analiz Paneli

Bu proje, resmi adli istatistikler ile sosyal medya/forum verilerini (Ekşi Sözlük vb.) bir araya getirerek kadınlar, gençler ve öğrenciler için bölgesel bir güvenlik ve adalet analiz paneli sunar.

# 🚀 Özellikler
- **Resmi Veriler:** Bölgesel suç oranlarının Türkiye geneli dağılım yüzdelerini gösterir.
- **Sosyal Hafıza:** Şehir bazlı olarak internette kullanıcıların uyardığı kritik/riskli bölgeleri listeler.
- **Kullanıcı Dostu Arayüz:** Gradio kütüphanesi kullanılarak geliştirilmiş kolay bir web arayüzüne sahiptir.

## 🛠️ Kullanılan Teknolojiler
- Python 3
- Pandas (Veri Analizi)
- Gradio (Web Arayüzü)
